## 命名規則について
可読性を重視するので、ゲーム開発における慣習やMicrosoft (Win32 API / DirectX)の規約をそのまま持ってくるものとします。

```
### 4.3 ネーミング規約

* クラス/構造体: `PascalCase`
* 関数/メソッド: `PascalCase`
* 変数: `camelCase`
* メンバ変数: `m_camelCase`
* 定数/Enum: `kPascalCase` または `ALL_CAPS`

### 4.4 ファイル命名規則
クラス名とファイル名の不一致はナビゲーションの妨げになります。

* **基本ルール:** ファイル名は、そのファイルに含まれる主要なクラス名と**完全に一致（PascalCase）**させてください。
* **拡張子:**
    * C++ ヘッダ: `.h`
    * C++ ソース: `.cpp`
    * シェーダー: `.hlsl`
    * インライン実装: `.inl`
* **原則:** 1つのファイルには1つの主要クラスのみを定義します（小さなヘルパー構造体などは例外）。
```
